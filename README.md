# Week 11 - Vector Embeddings with ChromaDB

## Project Title
Creating and Storing Vector Embeddings using ChromaDB

## Objective
To generate text embeddings using Sentence Transformers and store them in ChromaDB for semantic search.

## Technologies Used
- Python
- Sentence Transformers
- ChromaDB
- Pandas
- NumPy
- Jupyter Notebook

## Dataset
10 text documents related to Artificial Intelligence.

## Implementation
1. Created 10 AI text documents.
2. Generated vector embeddings.
3. Stored embeddings in ChromaDB.
4. Added document metadata.
5. Performed Top-5 similarity searches.
6. Compared semantic search with keyword search.

## Result
Successfully generated and stored vector embeddings and performed semantic retrieval using ChromaDB.
